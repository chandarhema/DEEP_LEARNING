## Deep Learning – Practical Learning & Industry Perspective
This repository contains the practical labs and implementations completed as part of my Deep Learning course.
Rather than treating these exercises as lab assignments alone, I am using them to build a strong understanding of 
how deep learning concepts are applied in real-world and industrial scenarios.

The repository covers the complete deep learning workflow, from fundamental concepts and model development to optimization,
regularization, normalization, and model evaluation.

### Topics Covered

* Neural Networks and Forward/Backward Propagation
* PyTorch fundamentals
* Dataset preparation and Data Loaders
* Model architecture design
* Loss functions
* Optimization algorithms

  * SGD
  * Momentum
  * AdaGrad
  * Adam
* Batch Normalization from scratch
* Layer Normalization
* Dropout from scratch
* Model training and evaluation
* Regularization techniques
* Performance comparison of different approaches
### Learning Objective

The main goal of this repository is to go beyond simply completing course requirements and develop an
**implementation-oriented understanding of deep learning**.

Each lab is approached with two perspectives:

1. **Academic perspective** – understanding the underlying concepts, mathematics, and algorithms.
2. **Industrial perspective** – understanding how these techniques contribute to building, training, evaluating, and
3. improving practical machine learning and deep learning systems.

This repository will continue to grow as I learn and implement additional deep learning concepts, with an emphasis on 
**hands-on experimentation, reproducibility, and practical application**.
